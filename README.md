# Coloreus

Coloreus is a small color guessing game I made using HTML, CSS, and JavaScript. You can generate a random color and try to match it using the RGB sliders. Once you make your guess, you get a score based on how close you were.

I went with a dark theme and the Press Start 2P font because I like the retro game look. It's a small project, but it was fun to make and helped me learn more about JavaScript.
